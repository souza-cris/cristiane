# Data Model: Content Restructure

**Date**: 2026-07-25

## Entities

### Story

A Markdown file in `_posts/` following Jekyll naming convention with enriched front matter.

**File**: `_posts/YYYY-MM-DD-title-slug.md`

**Front matter fields**:

| Field | Required | Description |
|-------|----------|-------------|
| `layout` | Yes | Always `story` |
| `title` | Yes | Story title |
| `date` | Yes | Publication date (YYYY-MM-DD) |
| `length` | Yes | `short` or `long` |
| `category` | Yes | One of: `AI`, `Leadership`, `Conference`, `ISD` |
| `tags` | No | List of free-form tags |
| `tldr` | Yes | 1–2 sentence summary |

**Body sections**:
- Main body (Markdown)
- Optional: citation/credit block
- Optional: "what I'm exploring next" section

**Derived fields** (auto-generated by Jekyll):
- `post.url` — permalink to the story detail page
- `post.excerpt` — first paragraph

### Bookmark

An entry in `_data/bookmarks.yml`.

**Structure**:

```yaml
- title: "Example Paper Title"
  type: "paper"
  topicTags:
    - "AI"
    - "NLP"
  whyItMatters: "2–4 sentences explaining relevance"
  keyTakeaway: "1 sentence core insight"
  link: "https://example.com"
  addedDate: "2026-07-25"
  source: "arXiv"
```

| Field | Required | Description |
|-------|----------|-------------|
| `title` | Yes | Display name of the resource |
| `type` | Yes | One of: `paper`, `book`, `talk`, `tool`, `dataset`, `more` |
| `topicTags` | Yes | List of 2–5 topic tags |
| `whyItMatters` | Yes | 2–4 sentences on relevance |
| `keyTakeaway` | Yes | 1 sentence core insight |
| `link` | Yes | External URL to the resource |
| `addedDate` | Yes | Date added (YYYY-MM-DD), used for sorting |
| `source` | No | Source attribution (e.g., "arXiv", "O'Reilly") |

### Research Data

Structured data in `_data/research.yml`.

**Structure**:

```yaml
interests:
  - "Instructional Systems Design and AI integration"
  - "Human-centered AI in education"
  - "Leadership in technology organizations"

publications:
  - title: "Example Publication Title"
    authors: "Souza, C. et al."
    venue: "Conference Name 2026"
    year: 2026
    status: "published"
    link: "https://doi.org/..."
  - title: "Work in Progress"
    authors: "Souza, C."
    venue: ""
    year: 2026
    status: "in progress"
    link: ""

methods:
  - "Qualitative research methods"
  - "Mixed-methods design"
  - "Survey design and analysis"
```

| Section | Description |
|---------|-------------|
| `interests` | List of research interest strings (bullet list) |
| `publications` | List of publication objects with title, authors, venue, year, status, link |
| `publications[].status` | One of: `published`, `in progress`, `under review` |
| `methods` | List of methods/tools strings (bullet list) |

## Relationships

```text
_config.yml (site metadata, social links)
    └── Referenced by: default layout (nav, footer, home page)

_posts/*.md (stories)
    └── Listed by: stories.md index + stories/*.md filter pages
    └── Rendered by: story.html layout

_data/bookmarks.yml (bookmarks)
    └── Rendered by: bookmarks.md index + bookmarks/*.md filter pages

_data/research.yml (research data)
    └── Rendered by: research.md page
```

## Validation Rules

- Stories MUST include `layout: story`, `title`, `date`, `length`, `category`, and `tldr` in front matter
- Story `length` MUST be one of: `short`, `long`
- Story `category` MUST be one of: `AI`, `Leadership`, `Conference`, `ISD`
- Bookmarks MUST have `title`, `type`, `topicTags`, `whyItMatters`, `keyTakeaway`, `link`, and `addedDate`
- Bookmark `type` MUST be one of: `paper`, `book`, `talk`, `tool`, `dataset`, `more`
- Publications MUST have `title`, `authors`, `year`, and `status`
- Publication `status` MUST be one of: `published`, `in progress`, `under review`
