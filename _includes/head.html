{%- comment -%} How this page describes itself, to a search engine and to anything that unfurls a link. The three values below are computed ONCE and reused, which is the whole point: the canonical address, the preview address and the structured-data address must be the same string, or a search engine has to guess which page it is looking at. Deriving them from one expression is what makes that impossible to get wrong. page_description falls back through the page's own summary, then a story's tldr — so every existing story already has a real description — and finally the site default. It is never blank. {%- endcomment -%} {%- if page.url == '/' -%} {%- assign page_title = site.title -%} {%- else -%} {%- assign page_title = page.title | append: ' | ' | append: site.title -%} {%- endif -%} {%- assign page_description = page.description | default: page.tldr | default: site.description | strip_html | normalize_whitespace | truncate: 160 -%} {%- assign page_url = page.url | absolute_url -%} {%- assign page_image = page.image | default: '/assets/og/default.png' | absolute_url -%} {{ page_title }} {%- comment -%} One authoritative address per page. The 404 gets none: it is not a page anyone should reach deliberately, and a canonical would invite indexing it. {%- endcomment -%} {%- unless page.url contains '404' %} {%- endunless %} {%- comment -%} Link previews. Two vocabularies, because the common services do not all read the same one. Both quote page_url, so they cannot disagree with the canonical. {%- endcomment -%} {% include structured-data.html page_url=page_url page_title=page_title page_description=page_description page_image=page_image %} {%- comment -%} Site icon. Three files: modern browsers take the SVG, older ones fall through to the .ico, and iOS reads the touch icon for a home-screen tile. These use relative_url, not absolute_url. An internal link wants a path; only something quoted by another site needs the full address. {%- endcomment -%}
