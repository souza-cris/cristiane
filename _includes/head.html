The three values below are computed ONCE and reused, which is the whole point: the canonical address, the preview address and the structured-data address must be the same string, or a search engine has to guess which page it is looking at. Deriving them from one expression is what makes that impossible to get wrong. page_description falls back through the page's own summary, then a story's tldr — so every existing story already has a real description — and finally the site default.
